## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/chizostudio/wallpaper-world.git
```

Enter the project folder:

```bash
cd wallpaper-world
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🌐 Deployment

Chizo Studio is designed to be deployed using GitHub Pages and GitHub Actions.
